# Security policy

This early-stage static analysis tool does not execute resource or configuration code. It may read locally stored configuration files, so do not commit real server.cfg files to public Git repositories. However, no static tool is a substitute for isolating untrusted material.

If you discover a vulnerability in the analyzer, please avoid posting exploit details in a public issue. Contact the maintainer through GitHub's private vulnerability reporting feature if enabled, or ask for a secure contact channel without sharing sensitive details.

Do not include private scripts, credentials or session tokens in bug reports.
